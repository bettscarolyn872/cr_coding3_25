## Please read the following before the Week 4 class:

The **NVIDIA PilotNet blog post** is your bridge from traditional computer vision to neural networks. It demonstrates an end-to-end learning approach, where the neural network is trained to map raw camera images directly to steering commands, effectively skipping the explicit, rule-based planning steps common in traditional robotics.

This contrasts sharply with the manual parameter tuning you saw with Canny, showing how a system can learn to drive and be more robust to variations in lighting and environment than hand-written code.

By examining the structure of PilotNet's CNN architecture (which is built on the convolution operations we discussed), you'll gain practical context for the neural network concepts we will be building in Week 4.

[**NVIDIA Blog post**: Researching and Developing an Autonomous Vehicle Lane-Following System](https://developer.nvidia.com/blog/researching-and-developing-an-autonomous-vehicle-lane-following-system/)
